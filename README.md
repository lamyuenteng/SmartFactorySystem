# Smart Factory Monitoring Platform

A modern Smart Factory Monitoring Platform built with ASP.NET Core, React, PostgreSQL, Redis, Docker, and Azure.

## Goals

- Learn ASP.NET Core
- Learn React
- Learn REST APIs
- Learn Cloud Deployment
- Learn Docker
- Learn CI/CD
